IMPORTANT SECURITY NOTES

Do not put these directly in frontend files:
- Telegram bot token
- MongoDB URI
- Admin password
- SMTP email password
- Any supplier/API key

Put secrets in Vercel Environment Variables instead.
Main secret/env names used by the server:
- MONGODB_URI
- TELEGRAM_BOT_TOKEN
- TELEGRAM_CHAT_ID
- ADMIN_EMAIL
- ADMIN_PASSWORD
- ADMIN_2FA_ENABLED
- SMTP_HOST
- SMTP_PORT

- SMTP_PASS
- SMTP_FROM
- ALLOWED_ORIGINS


FAST EDIT MAP

1. Admin login email/password
Where to edit:
- Vercel Dashboard > nickstore project > Settings > Environment Variables

Variables:
- ADMIN_EMAIL controls the admin login email.
- ADMIN_PASSWORD controls the admin login password.
- ADMIN_2FA_ENABLED=true turns email 2FA on.
- SMTP_USER should be nickstore642@gmail.com if you want NickStore Gmail to send login/reset codes.
- SMTP_PASS must be a Gmail App Password, not the normal Gmail password.
- SMTP_FROM can be NickStore <nickstore642@gmail.com>.

After changing:
1. Redeploy in Vercel.
2. Log out from admin.
3. Log in again.

Code that uses it:
- server/index.cjs
- Search for: adminEmail, adminPassword, adminTwoFactorEnabled

20. API security controls
Where to edit:
- server/index.cjs

Search for:
- allowedOrigins
- createRateLimiter
- authRateLimit
- orderRateLimit
- requireAdmin
- sanitizePublicProduct
- sanitizeOrder

What each one does:
- allowedOrigins decides which websites can call the API from a browser.
- createRateLimiter limits spammy requests.
- authRateLimit protects login and 2FA.
- orderRateLimit protects order creation.
- requireAdmin blocks admin changes without a valid admin session token.
- sanitizePublicProduct removes private product fields before customers see them.
- sanitizeOrder removes private receipt data from public order lookup.


21. API route labels
File:
- server/index.cjs

Routes:
- POST /api/auth/login
  Admin login. May require 2FA.
- POST /api/auth/verify-2fa
  Verifies email code and creates an admin session.
- GET /api/games
  Public/admin game list. Public sees active games only.
- POST /api/games
  Admin creates a game.
- PUT /api/games/:id
  Admin edits a game.
- DELETE /api/games/:id
  Admin deletes a game.
- GET /api/products
  Public/admin product list. Public gets sanitized active products only.
- POST /api/products
  Admin creates a product.
- PUT /api/products/:id
  Admin edits a product.
- DELETE /api/products/:id
  Admin deletes a product.
- GET /api/settings/public
  Public settings, currently receipt checker status.
- PUT /api/settings/receipt-checker
  Admin turns receipt checker on/off.
- POST /api/catalog/seed-market
  Admin imports starter market catalog.
- POST /api/catalog/import-pricelist
  Admin imports CSV pricelist.
- POST /api/catalog/markup
  Admin applies markup percent.
- POST /api/catalog/prune-to-pricelist
  Admin removes non-pricelist games/products.
- GET /api/orders
  Admin sees all orders. Public can search by order_number only.
- POST /api/orders
  Customer creates order. Backend recalculates price.
- PUT /api/orders/:id
  Admin updates an order.
- DELETE /api/orders/:id
  Admin deletes an order.
- POST /api/telegram/test-order
  Admin sends a test Telegram order.
- GET /api/payment-methods
  Public/admin payment method list. Public sees active only.
- POST /api/payment-methods
  Admin creates payment method.
- PUT /api/payment-methods/:id
  Admin edits payment method.
- DELETE /api/payment-methods/:id
  Admin deletes payment method.

24. Common emergency fixes

If admin cannot log in:
- Check ADMIN_EMAIL and ADMIN_PASSWORD in Vercel env.
- If 2FA email is broken, set ADMIN_2FA_ENABLED=false temporarily.
- Redeploy.

If email 2FA/reset code does not send:
- Check SMTP_HOST=smtp.gmail.com.
- Check SMTP_PORT=587.
- Check SMTP_USER=nickstore642@gmail.com.
- Check SMTP_PASS is a Gmail App Password.
- Redeploy after changing env vars.

If Telegram order does not arrive:
- Check TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID.
- Make sure you started the bot/chat.
- Use admin dashboard test Telegram button.

If customers see wrong price:
- Check product cost_price, markup_percent, price, original_price in admin Products.
- Backend uses product_id to recalculate the order total.

If receipt image does not show in admin:
- Check the order has receipt_image_url in MongoDB.
- Check src/components/admin/OrderDetailModal.tsx.
- Make sure you are logged in with a fresh admin session.

If public products expose private data:
- Check server/index.cjs.
- Search for sanitizePublicProduct.
- Do not include cost_price, supplier_code, provider_slug, or market_reference in public output.

If too many games/products show:
- Run the prune-to-pricelist admin action or API.
- Public only shows active games/products.
